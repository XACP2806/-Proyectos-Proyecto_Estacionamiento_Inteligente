## Descripción de la situación

La situación seleccionada es un **Estacionamiento Inteligente**.

En un estacionamiento pueden ingresar y salir varios vehículos durante el día. El lugar cuenta con una cantidad limitada de espacios, por lo que es necesario mantener un control de cuáles están disponibles y cuáles están ocupados.

En base a esta situación se compararan los modelos de Memoria Compartida y Paso de Mensajes para encontrar cual es el mas adecuado para este caso.
